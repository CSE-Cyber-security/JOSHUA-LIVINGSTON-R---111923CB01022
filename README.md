# Week 2 Python Task: Factorial Calculator

## Objective
Calculate the factorial of a number entered by the user.

## Requirements
- Python 3
- A terminal or command prompt

## How to Run
Run the following command from this folder:

```bash
python factorial.py
```

If your system uses `python3`, run `python3 factorial.py`.

## Sample Output
```text
Enter a number: 5
Factorial of 5 = 120
```

## Logic
The program uses a `while` loop to multiply consecutive integers from 1 to the input number. Negative inputs are handled separately, and the factorial of 0 is 1.
